# Bibliography errata for HAIO-GATS v0.1.0

Status: Editorial correction proposal for review.

This notice documents two bibliography findings in HAIO-GATS v0.1.0,
References, printed page 16 (PDF page 17). It does not replace or
modify the deposited specification, change normative requirements,
or establish conformity with an external standard.

Tracking issue: https://github.com/paulhugel/haio-gats/issues/8

## Reference [12]: RFC 9162 authors

VERIFIED: The deposited bibliography includes Langley and Kasper
among the authors of RFC 9162. The RFC Editor identifies its authors
as Ben Laurie, Eran Messeri, and Rob Stradling.

Proposed corrected citation:

Laurie, B., Messeri, E., & Stradling, R. (2021).
Certificate Transparency Version 2.0. RFC 9162.
https://www.rfc-editor.org/rfc/rfc9162

Authoritative record:
https://www.rfc-editor.org/info/rfc9162/

## Reference [6]: NIST release identification

VERIFIED: The base publication DOI resolves to NIST SP 800-53,
Revision 5, whose PDF identifies updates through December 10, 2020.
NIST separately identifies control-catalog Release 5.2.0 as finalized
on August 27, 2025.

The proposed correction explicitly identifies Release 5.2.0.
It does not establish which release was originally consulted.

Proposed citation:

National Institute of Standards and Technology.
(2020; control-catalog Release 5.2.0, August 27, 2025).
Security and Privacy Controls for Information Systems and
Organizations (NIST SP 800-53, Revision 5).
https://doi.org/10.6028/NIST.SP.800-53r5

Release-specific sources:
- NIST release announcement:
  https://csrc.nist.gov/projects/risk-management/sp800-53-controls/public-comments
- NIST, Summary of Changes: NIST SP 800-53 Release 5.2.0:
  https://csrc.nist.gov/files/projects/Risk-Management/800-53%20Comment%20Site/SP800-53-r5.2.0-changes.pdf
- NIST catalog access:
  https://csrc.nist.gov/projects/cprt/catalog

The change summary identifies the release but is not the complete
control catalog. This citation clarification does not establish that
HAIO-GATS incorporates every control or change in Release 5.2.0.

## Evidence and limits

Codex compared the deposited bibliography with primary-source records.
These are executor checks, not independent review or validation.
The deposited v0.1.0 PDF remains authoritative.
