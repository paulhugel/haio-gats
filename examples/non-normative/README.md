# Non-normative examples

This directory is reserved for illustrative event sequences, schema instances,
and interoperability examples.

Examples do not create requirements, establish secure defaults, demonstrate
conformance, or authorize operational use. Each future example must identify:

- the specification version and requirements illustrated;
- whether actors, keys, resources, and evidence are synthetic;
- omitted controls and residual risks;
- the expected validation result; and
- the distinction between self-check and independent verification.

No example has been approved for inclusion in this Phase 0 candidate.
